Practical Game Studio adapts architectural ideas from:

> Claude Code Game Studios
> https://github.com/Donchitos/Claude-Code-Game-Studios
> Copyright (c) 2026 Donchitos

Adapted patterns include responsibility-focused role definitions, workflow/playbook organization, guided onboarding, prototype and vertical-slice separation, review modes, persistent project state, structured document templates, validation gates, and issue/milestone workflows. PGS reimplements these ideas as a smaller Codex-native framework and does not reproduce the source framework in full.
