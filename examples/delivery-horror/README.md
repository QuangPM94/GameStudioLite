# Delivery Horror Example

This example demonstrates artifact shape for a tiny hypothesis: whether route planning under limited light can make a routine delivery feel tense. It is documentation-only in Phase A; it does not claim a playable build or observed playtest.

- `sample-game-brief.md` shows a concise brief.
- `sample-evaluation.md` shows an inference-only Player Advocate review with the required disclaimer.

Phase G will dogfood PGS against a real delivery-horror prototype and replace inference with observed evidence.
